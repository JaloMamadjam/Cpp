# Conversor e Calculadora de Bases Numéricas

Este é um aplicativo feito com **Qt (C++)** que permite:

- Converter números entre as bases **binária, octal, decimal e hexadecimal**;
- Realizar **operações aritméticas (+, -, ×, ÷)** entre números em diferentes bases;
- Exibir o **processo passo a passo** de conversão entre as bases;
- Mostrar resultados em diversas representações (complemento de 2, etc.).

## 🚀 Funcionalidades

### Conversor de Bases
- Entrada do número e seleção da base de entrada;
- Conversão automática para as outras três bases;
- Visualização do processo de conversão (divisões sucessivas, complemento de dois).

### Calculadora de Bases
- Dois operandos com bases independentes;
- Escolha do operador (+, -, ×, ÷);
- Exibição do resultado em base escolhida;
- Suporte a números negativos e divisão com tratamento de erro.

## 🧱 Tecnologias Usadas

- Qt 5 / Qt 6 (com Qt Creator)
- C++ moderno
- Interface gráfica com Qt Widgets
